# step-03 — login

請將此步驟的截圖放入此資料夾。

## 命名規則

| 檔案 | 用途 |
|------|------|
| `original.png` | 原始操作截圖（未加任何標註） |
| `annotated.png` | 已加箭頭、框線、圈選或步驟編號的標註圖片 |

## manual.ts 路徑寫法

```ts
image: "/manual/getting-started/login/step-03/annotated.png"
```

## 注意事項

- 圖片格式建議使用 PNG 或 WebP
- 路徑以 `/manual/` 開頭，不可使用本機絕對路徑
- 更新圖片時請保持路徑不變，避免教學連結失效
- 僅需提供其中一個版本也可（沒有標註版就只放 original.png）
